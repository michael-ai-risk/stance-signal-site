# Stance & Signal website

GitHub Pages site for Stance & Signal, built with Astro.

- English is the canonical public entry.
- Real Estate is the first professional vertical, not the master brand itself.
- No contact email, phone, client name, project outcome, or testimonial is invented here.
- Public evidence links must point to stable canonical locations only.

The active site lives in `web/` (Astro). `.github/workflows/deploy.yml` builds it
and publishes `web/dist` to GitHub Pages on every push to `main`.

`site/` is the previous static HTML/CSS build. It is kept for reference and is no
longer deployed; it is not being modified going forward. See `web/README.md` for
the current structure, pending photography assets, and local dev commands.
